# Diagram sources

| File | Diagram | How to edit or regenerate |
|---|---|---|
| as_is.bpmn, to_be.bpmn | BPMN 2.0 processes | Open in Camunda Modeler or [demo.bpmn.io](https://demo.bpmn.io). Generated by `bpmn_build.py`; images rendered with bpmn-js |
| *.puml | UML use case, activity, sequence, class, state; wireframes (Salt) | PlantUML with Graphviz: `java -jar plantuml.jar -tsvg -o ../img *.puml` |
| style.iuml | Shared palette and fonts for all PlantUML diagrams | Included by every `.puml` file |

**Palette:** navy `#1F3A5F` structure · blue `#3B6EA8` people and user steps · teal `#2A7F8E` systems · amber `#C98A1B` decisions and business rules · red `#B5452F` compliance risk and pain points.

Rendered images are in [../img](../img).
